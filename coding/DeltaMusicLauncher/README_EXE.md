# DeltaMusic v1.2.0 EXE 版：从这里开始

这是给 Windows 新手准备的版本。**不需要安装 Python，也不要运行 PlayerHost。**

当前版本新增了个人曲目右键重命名/删除，以及一次选择或拖入多个 MIDI 的安全导入。默认播放器的 F10 紧急停止适用于内置曲目和安全 MIDI；高级 Python 曲目的停止逻辑仍由脚本作者负责。

## 只要三步

1. 把 `DeltaMusicLauncher.zip` 完整解压到一个普通文件夹，例如桌面或下载文件夹。不要在压缩包预览窗口内直接运行。
2. 双击解压后根目录的 `DeltaMusic.exe`。
3. 在图形界面中选择曲目，点击“开始演奏”。此时才会出现 Windows 的管理员权限提示；同意后，播放器会显示倒计时。切回游戏、拿出口琴，等待倒计时结束即可。`F10` 是紧急停止键；若能切回启动器，也可点击“紧急停止”。

`DeltaMusicPlayerHost.exe` 是后台辅助播放器，**不要单独双击它**。请不要移动或删除它、`launcher` 文件夹，或任何曲目文件夹。

## Windows 弹出保护提示怎么办

本项目是社区发布的未签名 EXE，Windows SmartScreen 可能会显示“Windows 已保护你的电脑”。只从发布者提供的官方位置下载，并先核对发布者给出的 SHA-256 校验值；确认文件来源和值均正确后，才可在该提示中选择“更多信息”→“仍要运行”。不认识来源或校验不一致时，请删除文件，不要运行。

## 导入和维护自己的曲库

启动器会将个人曲库存到：

```text
%LOCALAPPDATA%\DeltaMusic\user_library\
```

- **导入 MIDI（手动设置）**：选择一首 `.mid` / `.midi`，自行设置显示名称、曲目 ID 和八度偏移。
- **选择 MIDI（可多选）/ 拖放 MIDI**：可从其他文件夹选多个 MIDI，或直接拖到界面中的投放框。它们会以安全模式导入，显示名称使用文件名；英文文件名生成英文 ID，中文文件名生成拼音 ID，重复时自动追加 `1`、`2`、`3`。
- **导入 Python + MIDI（高级）**：只导入你自己写的或完全信任来源的 `.py` 和 MIDI。导入时不会执行 Python；开始演奏时仍会要求你明确确认是否以管理员权限运行。高级曲目的作者需要自行实现停止逻辑；启动器无法替第三方 Python 代码强制安全停止。
- **导入曲目包**：导入其他用户导出的 `.dmsong` 文件。

右键个人曲目可以重命名显示名称或永久删除它；内置曲目不能修改。删除会移除该曲目的全部文件，操作前会再次确认。

更新 EXE 发布包不会删除这里的个人曲库。若启动器无法打开，请重新完整解压 ZIP，不要只复制其中的一个 EXE。
