个人曲库保存在 %LOCALAPPDATA%\DeltaMusic\user_library，而不是发布包目录。

这样重新下载或升级 DeltaMusic 时，不会覆盖自己的曲目。

请用启动器中的“导入 MIDI（手动设置）”、“选择 MIDI（可多选）”、
“导入 Python + MIDI（高级）”或“导入曲目包”维护曲库。

也可把一个或多个 .mid / .midi 文件拖到启动器的投放框；它们会自动以安全模式导入。
英文文件名使用英文 ID，中文文件名使用拼音 ID；发生重复会自动追加 1、2、3。

右键个人曲目可以重命名显示名称或永久删除它。不要把未知来源的 Python 曲目以管理员权限运行。
